Stage 3 · Autonomy

Six steps.
How does it keep going?

Put the model
in a loop.

while not done: step = llm(goal + history) result = run(step) history += result

Same tools as before. The only new thing is letting it go again — after seeing what happened.

Stage 5 · Coordination

Three problems.
One message.

Messy requests
need a plan.

plan = llm("break down: " + request)for task in plan: run_agent(task)

Write the to-do list first, then work through it — and update it when things change.

PlanningTask decompositionRe-planning
“Order A is late, order B arrived damaged, and I just moved — new address is 12 Lê Lợi.”

  2. Check on the late package (order A)
  3. Update the address
  1. ✓Update address on order A — it hasn't shipped yet!
  2. ✓Refund the damaged item (order B)
  3. ✓Ship order A faster, to the new address

↻ re-planned after get_order(A): “not shipped” — address first, or it goes to the old address.

The real lesson

Climb only as high
as your problem.

Each step up adds power — and cost, latency and new ways to fail.

Most features should stop lower than you think.

  1. Multi-agentmany domains, different permissionsBlack Friday
  2. Agentsteps depend on what it findssize exchanges
  3. Workflowsteps known in advance — just code themrefund within policy
  4. + Toolsone lookup or one actionorder status
  5. + Knowledgeanswers from your docsFAQ bot
  6. Prompttext in, text outproduct descriptions
Every box has a reason

AI agents aren't a pile of AI concepts.

They're engineering answers to the limits of an LLM.
